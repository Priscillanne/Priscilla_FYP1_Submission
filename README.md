## About the project

A low-cost attendance system that runs on staff smartphones. Each check-in passes four layers of checks:

1. **Face ID** on the phone confirms a live, authorised user.
2. **1:1 face verification** compares the check-in selfie with the staff member's own registered face.
3. **Registered phone**: each account is linked to one phone.
4. **Location checks**: fake GPS flag, distance from the office, GPS accuracy, reading age and impossible movement.

Each check-in is then **Accepted**, sent to **HR review**, or **Rejected**. HR uses a web dashboard to review flagged check-ins, manage staff and change the company rules.
